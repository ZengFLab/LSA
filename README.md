# LSA: Latent space alignment for cross-system perturbation response prediction
Transfer perturbation mechanisms from perturbation atlas to query.

## Installation
1. Create a virtual environment
```bash
conda create -n LSA python=3.10 scipy numpy pandas scikit-learn && conda activate LSA
```

2. Install [PyTorch](https://pytorch.org/get-started/locally/) following the official instruction. 
```bash
pip3 install torch torchvision --index-url https://download.pytorch.org/whl/cu126
```

3. Install LSA
```bash
pip3 install LSA-sc
```
